## Tugas Teknikal
### Tugas 1 — Deteksi Anomali Data SQL Mudah
Tabel pasien mengandung tiga masalah kualitas data. Tulis tiga query SQL terpisah untuk mendeteksi masing-masing masalah berikut: 1. Pasien yang belum memiliki no_bpjs (nilai NULL) 2. no_bpjs yang dimiliki lebih dari satu pasien (duplikat) 3. Pasien dengan tgl_lahir yang melebihi tanggal hari ini (tidak valid)
💡 Petunjuk
Gunakan IS NULL, GROUP BY ... HAVING COUNT(*) > 1, dan CURDATE().

### Tugas 2 — Perbaikan N+1 Query SQL / ORM Menengah
Kode berikut digunakan untuk menampilkan daftar rekam medis beserta nama dokternya, namun mengalami N+1 query problem:
// ❌ Kode bermasalah — mengeksekusi 1 + N query ke database $list = RekamMedis::all(); // Query #1: ambil semua rekam medis foreach ($list as $rm) { $dokter = Dokter::find($rm->id_dokter); // Query #2..N+1: satu per baris! echo $rm->diagnosa . ' - ' . $dokter->nama_dokter; }
Dengan data sampel 8 baris rekam_medis, kode ini mengeksekusi 9 query. Jika tabel berisi 50.000 baris, akan ada 50.001 query setiap halaman dimuat. Selesaikan dua sub-tugas berikut:
  • Tulis ulang kode di atas menggunakan eager loading (ORM) untuk menghilangkan N+1
  • Tulis query SQL murni alternatifnya menggunakan JOIN

### Tugas 3 — Query Laporan Agregasi SQL Menengah
Manajemen rumah sakit meminta laporan dengan format berikut: Tampilkan nama dokter, jumlah pasien unik yang ditangani, total kunjungan, dan total biaya — diurutkan dari total biaya tertinggi. Output yang diharapkan dari data sampel:

💡 Petunjuk
Gunakan JOIN, COUNT(DISTINCT id_pasien), COUNT(*), SUM(biaya), GROUP BY, dan ORDER BY.

### Tugas 4 — Tambah Constraint & Index SQL DDL Menengah
Saat ini tabel pasien tidak memiliki constraint yang mencegah data anomali masuk. Tulis perintah ALTER TABLE untuk menambahkan: 1. UNIQUE constraint pada kolom no_bpjs agar tidak bisa duplikat 2. CHECK constraint pada tgl_lahir agar tidak boleh melebihi hari ini 3. INDEX pada kolom id_pasien di tabel rekam_medis untuk mempercepat query JOIN
⚠ Catatan
Sebelum menambahkan UNIQUE constraint, data duplikat yang sudah ada harus dibersihkan terlebih dahulu. Tulis juga query untuk menghapus atau memperbaiki data duplikat tersebut.

### Tugas 5 — Stored Procedure Validasi SQL Lanjutan Lanjutan
Buat sebuah stored procedure bernama tambah_pasien yang menerima parameter: p_nama, p_tgl_lahir, p_no_bpjs, p_status_aktif Procedure ini harus melakukan validasi sebelum melakukan INSERT: 1. tgl_lahir tidak boleh melebihi hari ini → jika tidak valid, kembalikan pesan error 'tgl_lahir tidak valid' 2. no_bpjs tidak boleh sudah ada di tabel → jika duplikat, kembalikan pesan error 'no_bpjs sudah terdaftar' 3. Jika semua validasi lolos → lakukan INSERT dan kembalikan pesan 'pasien berhasil ditambahkan'
💡 Petunjuk
Gunakan DELIMITER, IF ... THEN ... ELSEIF ... END IF, SIGNAL SQLSTATE atau variabel output OUT p_pesan VARCHAR untuk mengembalikan pesan.
